# Support

Start with the [README](README.md) and [operations guide](docs/spec/09-operations.md). Use [GitHub Issues](https://github.com/matella/storm-codex/issues) for bugs, setup problems, and feature requests. Search for an existing issue before posting.

Include the app version or commit, OS, whether you use the desktop app or Docker, and the steps to reproduce it. A short, redacted log excerpt is usually more useful than a full archive. Remove tokens, account IDs, private paths, and replay chat. Use the [security policy](SECURITY.md) for vulnerabilities and the [contribution guide](CONTRIBUTING.md) for changes.
