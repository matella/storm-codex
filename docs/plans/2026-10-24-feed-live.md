# Plan — in-game live feed (server + page) — **DONE on 2026-10-24** (tasks 1→7)

> Spec: `docs/specs/2026-10-24-feed-live-en-partie-design.md` (decisions of 2026-10-24).
> Scope of this plan: server + `/live` page, proven by a simulator. The `client-rs` watcher
> (Hots-Overlay repo) and the spike on a matchmade game are next steps.

## Tasks

1. **`storm-replay` — chunked decoding.**
   `Protocol::decode_partial(kind, bytes, start_loop)` (stops cleanly on `Truncated`),
   public `StreamDecoder` + `StreamKind`, `Replay::{tracker,game}_events_raw()`.
   Test `tests/stream_decoder.rs` on the mini-corpus: 4 KB / 1 byte / pseudo-random size
   chunks = whole decoding; random bytes → never panics.
   Doc: `docs/spec/02-storm-replay.md`.
2. **Unit → hero table.** `examples/derive_hero_units.rs` (server) over the local archive
   (`PlayerSpawned.Hero` ↔ the same player's `details`) → committed `src/live/hero_units.json`, embedded
   via `include_str!`. Conflicts counted and reported.
3. **Pure reducer `src/live/state.rs`.** `LiveState::apply_tracker/apply_game`, filtered view
   `view(scope, me)`. Tests: committed replay replayed in chunks vs `storm-stats` parse (heroes,
   talents, deaths); visibility filter.
4. **Session + routes `src/live/{mod,api}.rs`.** `AppState.live`, `POST /api/live/chunk`
   (idempotence, `409`), `POST /api/live/end`, `GET /api/live`, `DELETE /api/live`, WS
   `live.updated`. Tests of the offset logic as a pure function.
   Doc: `04-serveur.md`, `05-api.md`, `07-evenements.md`.
5. **Simulator `examples/live_sim.rs`.** Lobby then 4 KB chunks in loop order,
   `--speed`, `--token`, `--url`.
6. **Front-end.** Types + `useLive` + WS invalidation in `api.ts`; pure helpers `live.ts` (+ vitest);
   `components/LiveGame.tsx`; `pages/Live.tsx`; navigation entry. Doc: `08-frontend.md`.
7. **Evidence.** `cargo test --workspace`, `cargo clippy --workspace -- -D warnings`, `npm test`,
   `npm run build`; release server + dev Postgres + `live_sim` → `/live` checked in the
   browser (idle / in progress / finished states, all three levels). `docs/STATUS.md`.
