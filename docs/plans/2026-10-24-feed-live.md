# Plan — feed live en partie (serveur + page) — **FAIT le 2026-10-24** (tâches 1→7)

> Spec : `docs/specs/2026-10-24-feed-live-en-partie-design.md` (décisions du 2026-10-24).
> Périmètre de ce plan : serveur + page `/live`, prouvés par simulateur. Le watcher `client-rs`
> (repo Hots-Overlay) et le spike sur partie matchmakée sont des étapes suivantes.

## Tâches

1. **`storm-replay` — décodage par morceaux.**
   `Protocol::decode_partial(kind, bytes, start_loop)` (s'arrête proprement sur `Truncated`),
   `StreamDecoder` + `StreamKind` publics, `Replay::{tracker,game}_events_raw()`.
   Test `tests/stream_decoder.rs` sur le mini-corpus : morceaux 4 Ko / 1 octet / tailles
   pseudo-aléatoires = décodage entier ; octets aléatoires → jamais de panique.
   Doc : `docs/spec/02-storm-replay.md`.
2. **Table unités → héros.** `examples/derive_hero_units.rs` (serveur) sur l'archive locale
   (`PlayerSpawned.Hero` ↔ `details` du même joueur) → `src/live/hero_units.json` committé, embarqué
   par `include_str!`. Conflits comptés et signalés.
3. **Réducteur pur `src/live/state.rs`.** `LiveState::apply_tracker/apply_game`, vue filtrée
   `view(scope, me)`. Tests : replay committé rejoué par morceaux vs parse `storm-stats` (héros,
   talents, morts) ; filtre de visibilité.
4. **Session + routes `src/live/{mod,api}.rs`.** `AppState.live`, `POST /api/live/chunk`
   (idempotence, `409`), `POST /api/live/end`, `GET /api/live`, `DELETE /api/live`, WS
   `live.updated`. Tests de la logique d'offset en fonction pure.
   Doc : `04-serveur.md`, `05-api.md`, `07-evenements.md`.
5. **Simulateur `examples/live_sim.rs`.** Lobby puis morceaux de 4 Ko dans l'ordre des loops,
   `--speed`, `--token`, `--url`.
6. **Front.** Types + `useLive` + invalidation WS dans `api.ts` ; helpers purs `live.ts` (+ vitest) ;
   `components/LiveGame.tsx` ; `pages/Live.tsx` ; entrée de navigation. Doc : `08-frontend.md`.
7. **Preuves.** `cargo test --workspace`, `cargo clippy --workspace -- -D warnings`, `npm test`,
   `npm run build` ; serveur release + Postgres dev + `live_sim` → `/live` vérifiée dans le
   navigateur (états repos / en cours / terminé, les trois niveaux). `docs/STATUS.md`.
